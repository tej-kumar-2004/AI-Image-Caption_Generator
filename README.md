# Task 03 - AI Image Caption Generator 🖼️

## 📌 Project Description

This project is an AI-based Image Caption Generator that analyzes an uploaded image and generates a meaningful description.

The application uses a pre-trained BLIP (Bootstrapping Language-Image Pre-training) vision-language model to understand the contents of an image and generate a human-readable caption.

The application is built using Python and Streamlit.

## ✨ Features

- Upload an image
- Display the uploaded image
- Analyze image contents using a pre-trained AI model
- Identify objects and activities in the image
- Generate a meaningful image caption
- Simple and interactive web interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Hugging Face Transformers
- BLIP
- PyTorch
- Pillow (PIL)

## 🤖 AI Model

The project uses the pre-trained:

`Salesforce/blip-image-captioning-base`

BLIP is a vision-language model designed for image understanding and image caption generation.
